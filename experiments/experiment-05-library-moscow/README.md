# Experiment 05: Library Requirements Using MoSCoW

## Aim

Categorize ten Library Management System requirements by impact on users and stakeholders and by feasibility within limited time, budget, and resources.

## Excel Workbook

[Download the completed Excel workbook](experiment-05-releaf-moscow.xlsx)

The workbook includes all ten supplied requirements, a MoSCoW category for each, and separate impact and feasibility justifications. It provides table filters, category dropdowns, color-coded categories, and frozen headers.

| Category | Requirements |
| --- | ---: |
| Must-Have | 3 |
| Should-Have | 3 |
| Could-Have | 2 |
| Won't-Have | 2 |

## Planning Context

The ReLeaf Community Library scenario assumes an eight-week web pilot, two developers, a part-time librarian reviewer, and a fixed small budget. Existing catalog, member and loan records, plus an email gateway, are assumed available. The pilot uses a responsive, English-first website with staff language assistance.

Won't-Have means deferred from this release. The requirements came from the task; resource constraints and priorities are illustrative planning judgments.

## Result

All ten requirements were categorized and justified. The workbook records a prioritization exercise rather than an implemented Library Management System.
